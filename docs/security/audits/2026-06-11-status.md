# 2026-06-11 audit — status of every finding

One row per finding of [the 2026-06-11 audit](2026-06-11.md): the critical, the forty-six
highs by ID, and the fifty-six medium bullets by their exact title. `tools/check-audit-ledger.sh`
runs in `make preflight` and in the Dagger ShellGates leg and fails when a finding has no row
or an empty evidence cell. It checks completeness, not truth: when a status changes, change the
row.

The retrospective written from this ledger is [2026-06-11-retrospective.md](2026-06-11-retrospective.md).

Status vocabulary: `fixed` — the defect is gone, and the evidence names the CHANGELOG entry and
a test or source location; `deleted with the feature` — the code that carried the defect no
longer exists; `refuses to boot` — the defect is still in source, but the server refuses to
start with that feature configured, so it is unreachable; `accepted` — a documented risk
acceptance; `open #N` — an issue; `not addressed` — nothing found. A `fixed` row whose module
was deleted afterwards keeps `fixed` and says so.
