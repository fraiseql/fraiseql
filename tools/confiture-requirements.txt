# Pinned install of confiture for the `integration (postgres)` leg, where
# `crates/fraiseql-cli/tests/migrate_against_confiture.rs` runs `fraiseql migrate` against it.
#
# `fraiseql migrate` is a wrapper: every verb shells `confiture migrate <verb> …`. The wrapper
# shipped for two releases calling `confiture status --source DIR` — a command and an option
# no confiture release has had — because its only tests self-skipped whenever confiture was
# present. The leg installs THIS confiture and runs the wrapper against it, so the call shape
# is checked against a version that is named here rather than against whatever PyPI serves on
# the day of the run (tools/check-ci-install-pins.sh: every install in CI names a version).
#
# Every version is exact, transitive ones included, for the same reason
# tools/scim-conformance-requirements.txt gives: the verdict is produced by third-party code,
# and an unpinned resolver hands someone else's release day the power to redden an untouched
# tree. Bumping is a deliberate commit that names the confiture whose CLI the wrapper was
# checked against. Regenerate with:
#
#     uv venv --python 3.14.2 /tmp/confiture
#     uv pip install --python /tmp/confiture/bin/python fraiseql-confiture==<version>
#     uv pip freeze --python /tmp/confiture/bin/python
#
# confiture needs Python 3.14 since 1.30.0. The Dagger integration base is `rust:1.94.1`
# (Debian 12, Python 3.11), so the leg installs uv (pinned in .dagger/main.go) and lets it
# fetch CPython 3.14.2 for this venv; regenerate on that interpreter. The CLI reference this
# pin was checked against is confiture's docs/reference/cli.md at tag v1.37.0
# (github.com/fraiseql/confiture); the wrapper's doc comment in
# crates/fraiseql-cli/src/commands/migrate.rs names the same tag.
